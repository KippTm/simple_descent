# Thoughts 

## Abilities:
All abilities start off unspecialized. 
Every 3rd or 5th level what is improved on level up can be changed:
    - Range
    - Duration
    - Damage
    - Number of projectiles
Levels only gain xp on succesful casts. 
Utility gain every but at slower pace.
**Physical abilities**:
1. Sweep:
    An arced mellee sweep. 
2. Stab: 
    A deeper straight stab.
3. Reflect: 
    Reflects all damage taken for a few frames or so.

**Magical abilities**:
1. Mana bolt: 
    Simple unaspected bolt
2. Mana shield: 
    A shield lasting for x seconds or till it has absorbed y damage.
    Only gains xp if it absorbs some damage after a few levels.

**Utility abilities**:
1. Dash: 
    Quick movement in one direction.
2. Haste: 
    General speed boost.
